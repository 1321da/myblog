# PRD — 个人博客系统（myblog）

> 版本：v1.1（已确认所有决策）
> 状态：已定稿

---

## 1. 产品概述

### 1.1 项目名称
myblog —— 个人博客系统

### 1.2 项目目标
构建一个轻量级的个人博客系统，包含两个端：

- **用户端**：面向访客的内容浏览入口，提供首页、文章详情页、标签筛选页、关于我页面。
- **博主管理后台**：面向博主（唯一管理员）的内容管理入口，提供管理员登录、后台仪表盘、文章管理、关于我管理。

### 1.3 核心价值
- **内容优先**：简洁、专注的阅读体验。
- **高效管理**：博主通过后台完成文章发布、编辑、删除与数据统计。
- **轻量易部署**：技术栈轻量、结构清晰，适合个人开发者快速部署与维护。

---

## 2. 目标用户

### 2.1 读者（访客）
- 特征：通过分享链接或搜索引擎访问博客的普通用户。
- 需求：浏览文章列表、阅读文章详情、按标签筛选、了解博主信息。
- 权限：仅可访问用户端页面，无法进入管理后台。

### 2.2 博主（管理员）
- 特征：博客的唯一所有者，使用账号密码登录。
- 需求：登录后台、查看文章统计、对文章增删改查、编辑「关于我」。
- 权限：可访问管理后台全部功能；未登录访问后台页面重定向到登录页。

---

## 3. 功能需求

### 3.1 用户端
- **首页**：文章列表按发布时间倒序，展示标题/摘要/发布时间/标签；分页（每页 10 条）；无文章时空状态提示。
- **文章详情页**：完整内容（标题/作者/时间/正文/标签）；Markdown 渲染（GFM，代码高亮）；上一篇/下一篇导航；访问不存在的 slug 提示「文章不存在」。
- **标签筛选页**：点击标签进入该标签下的文章列表。
- **关于我页面**：展示头像、个人简介、联系方式、社交链接。

### 3.2 管理后台
- **登录**：账号密码登录；错误提示不清空输入；成功跳转仪表盘；已登录访问登录页直接跳仪表盘。
- **仪表盘**：统计卡片（文章总数/已发布数/草稿数/本月新增数）+ 最近文章列表（5 条）。
- **文章管理**：列表（表格，标题关键词 + 状态筛选，分页）；新增/编辑（标题、摘要、正文、标签、状态）；删除（二次确认）。
- **关于我管理**：编辑头像、简介、联系方式、社交链接。

## 4. 已确认的技术决策

| 决策项 | 结论 |
|--------|------|
| 架构 | 动态全栈应用（Next.js + TypeScript） |
| 数据库 | SQLite + Drizzle ORM |
| 评论 | 不需要 |
| 「关于我」 | 后台可编辑 |
| 摘要 | 留空自动截取正文前 100 字 |
| 标签 | 自由填写（逗号分隔），点击进入筛选页 |
| 文章 URL | 自定义 slug，默认由标题生成，唯一 |
| 图片 | 文章插图用 Markdown 外链；头像上传存本地 |
| 草稿 | 用户端绝对不可见 |
| 删除 | 物理删除 |
| 本月新增 | 自然月内新增的文章数 |
| 首页分页 | 分页，每页 10 条 |
| 后台搜索 | 标题关键词 + 状态筛选 |
| 管理员账号 | 首次运行初始化，后台可改密码、登出、会话过期 |
| 登录安全 | bcrypt 密码哈希 + 登录限流 |
| Markdown | 支持 GFM + 代码高亮，渲染时 XSS 过滤 |
| 数据统计 | 仅文章统计，暂不做 PV/UV |
| SEO | 每篇文章生成 title/description/OG 标签 |

## 5. 非功能性需求

### 5.1 响应式设计
- 适配桌面（≥1024px）、平板（768–1023px）、手机（≤767px）。
- 移动端优先：窄屏导航折叠、文章卡片单列、表格转卡片式或横向滚动。
- 触控目标 ≥ 44×44px，移动端可读字号。
- 图片与代码块窄屏下自动缩放或横向滚动，不破坏布局。

### 5.2 安全
- 密码 bcrypt 哈希存储。
- 登录限流（防暴力破解）。
- Markdown 渲染过滤 XSS。
- 后台接口统一鉴权。

### 5.3 部署
- SQLite 需持久磁盘 → Docker 部署到 VPS / Railway / Render（不可用 Vercel）。
